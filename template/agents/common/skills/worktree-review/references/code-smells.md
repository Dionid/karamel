# Базовые запахи кода (Fowler baseline)

Опциональный справочник для §3 «Conventions / dead code» — когда репозиторий
не документирует свой стиль и нужен готовый набор ориентиров вместо
изобретения на ходу. Список — сокращённый набор запахов из *Refactoring*
(Fowler, гл. 3).

Два правила держат этот список на месте, а не поверх решения ревьюера:

- **Документированный стандарт репозитория побеждает.** Если `CLAUDE.md`,
  линтер или существующий код репозитория одобряют то, что запах бы отметил —
  запах не поднимается.
- **Это всегда суждение, а не жёсткое правило.** Помечайте находку как
  «возможно X», не как нарушение — и поднимайте её в отчёте только если она
  проходит фильтр §3 (заметность, актуальность для этого diff, что автор
  вероятно исправил бы).

| Запах | Что это | Как чинить |
| --- | --- | --- |
| Mysterious Name | Функция, переменная или тип, чьё имя не говорит, что оно делает или хранит. | Переименовать; если честное имя не находится — не найдено имя, потому что неясен сам дизайн. |
| Duplicated Code | Одна и та же форма логики повторяется в нескольких хунках или файлах diff'а. | Вынести общую форму, вызывать её из обоих мест. |
| Feature Envy | Метод чаще обращается к данным чужого объекта, чем к своим. | Перенести метод туда, к данным, которые он использует. |
| Data Clumps | Одни и те же несколько полей/параметров путешествуют вместе (тип, который просится на свет). | Собрать их в один тип и передавать его. |
| Primitive Obsession | Примитив или строка подменяет доменное понятие, достойное своего типа. | Дать понятию свой небольшой тип. |
| Repeated Switches | Один и тот же `switch`/каскад `if` по одному типу повторяется в разных местах diff'а. | Заменить полиморфизмом или одной картой, которую используют оба места. |
| Shotgun Surgery | Одно логическое изменение вынуждает разрозненные правки по многим файлам diff'а. | Собрать то, что меняется вместе, в один модуль. |
| Divergent Change | Один файл или модуль правится по нескольким несвязанным причинам. | Разделить так, чтобы каждый модуль менялся по одной причине. |
| Speculative Generality | Абстракция, параметр или хук добавлены под потребность, которой спека не называла. | Удалить; заинлайнить обратно до появления реальной потребности. |
| Message Chains | Длинная навигация `a.b().c().d()`, от которой не должен зависеть вызывающий. | Спрятать проход за одним методом на первом объекте. |
| Middle Man | Класс или функция, которые в основном только делегируют дальше. | Убрать посредника, звать настоящую цель напрямую. |
| Refused Bequest | Наследник, который игнорирует или переопределяет большую часть унаследованного. | Убрать наследование, использовать композицию. |

Пропускайте то, что уже проверяет тулинг (линтер, форматтер) — находка здесь
имеет смысл только там, где инструмент молчит.
