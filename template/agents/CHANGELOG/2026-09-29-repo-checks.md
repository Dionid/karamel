# Проверка обязательных составляющих репозиториев

На вкладке «Репозитории» — карточка «Обязательные составляющие»: у каждого
репозитория из `repos.json` проверяются закоммиченные `service.yaml`,
`CODEOWNERS` и охрана секретов (deny на `.env`, хук на Bash, `.env` в
`.gitignore`), по желанию — джоба `claude-mr-review` в CI. Кнопка «Показать
промпт» собирает задание агенту на недостающее; то же из терминала —
`./ops check`.
