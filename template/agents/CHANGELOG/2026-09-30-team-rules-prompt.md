# Промпт для настройки правил команды

На четвёртом шаге мастера, дашборде и во вкладке «Кастомизация» появилась
карточка с промптом, который помогает исследовать процессы команды и разложить
настройки по `AGENTS.md`, `IDENTITY.md`, `SOUL.md`, decisions, skills и hooks.
Она показывается, пока эти файлы остаются scaffold, и исчезает после настройки.
Репозиторий с незаполненным командным слоем по адресу без явного экрана сразу
открывает Мастер; после настройки дефолтом снова становится Дашборд.

Новый `AGENTS.md` сразу получает нейтральную Track-модель A/P/B/H/I/C и импорты
`IDENTITY.md`/`SOUL.md`. Командный промпт дополняет этот рабочий дефолт, а не
просит заново изобрести цикл по примеру Engineering agent.
