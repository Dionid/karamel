# PR не открывается без полного описания

`commit-and-mr/run.sh` открывает PR только с `--mr-description-file` по шаблону
`mr-description/template.md` — что и зачем, изменения по фичам, инфраструктура,
как проверить, риски — и отказывает до коммита, если раздела нет или он пуст.
Ход по уже открытому PR — `--existing-mr`, он никогда не открывает новый.
Проверка без токена — `describe.sh check`.
